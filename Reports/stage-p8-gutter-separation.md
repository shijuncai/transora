# 阶段 P8：栏缝（间隔区）必须切开——署名/地址不再与标题/正文黏连

样本：`Sample/Biodegradation.pdf`（Int. Microbiol. 8(3) 2005, 195–204，10 页，双栏期刊）
用户标注：绿色 = 署名行与「Present address」行；红色方框 = 「间隔区」，用于分隔不同段落。

---

## 1. 用户看到的现象

1. **「署名 + 标题」译成一段**：左栏 9 行作者名之后，右栏的标题接着排下来，
   中文变成「安赫尔·T·马丁内斯1* 玛丽埃拉·斯佩兰萨1 弗朗西斯科·J·鲁伊斯-杜埃尼亚斯1
   研究：微生物、化学，酶促作用方面…」——作者名和标题在同一块里。
2. **「地址 + 正文」译成一段**：`3Present address: University of Alcalá…` 与右栏摘要
   并成一句，中文成「3 现址：西班牙马德里… 酶（氧化还原酶）参与细胞壁成分的降解」。
3. **红框（间隔区）被无视**：两栏正文的行被左右拼成一条，段落变成
   「森林约占全球陆地 droxycinnamyl 的 27%…」，左右交错、中间留白。

---

## 2. 根因：行先被并成「假行」，分栏判据就永久失效

分层看，是三件事叠在一起：

| 层 | 事实 | 数值（本样本） |
|---|---|---|
| ① 行内字距阈值 | `max(1.6em, 12pt)` 判「同一行的两个 run 之间是不是词距」 | 正文 10 pt → 阈值 16 pt；**栏距只有 13.8 pt（1.38 em）** |
| ② 角标落在栏缝里 | 作者名末尾的 `1`（8.4 pt）正好填进缝里，把「名字 → 标题」压到 12.35 pt | 而阈值按 `max(字号)=21 pt` 算 → 33.6 pt，必然并合 |
| ③ 分栏判据 | `detectColumns` 找的是「**没有任何一行跨过**的竖缝」 | 假行跨过了缝 → 这条缝再也找不到 |

③ 是关键：一旦某一行跨过栏缝，整页的双栏识别就全部退化成「一栏」，
后面按 y 排序、按行距断段，左右两栏的行自然交错进同一段。所以修在「行」层面无效，
**必须在 run 层先把区域切开**。

---

## 3. 修法

### 3.1 `PDFRegionCutter`（新增，`Sources/HymnCore/PDF/PDFRegionCutter.swift`）

对一页的 run 做递归 XY 切分，切法与 `detectColumns` 同源，但对象是 run：

- **竖缝**：扫描线求「覆盖数 ≤ 1」的竖条（允许一条页眉/页码跨过去），宽度 ≥ 6 pt。
  成立条件刻意保守——两侧各 ≥ 3 个 run **且各 ≥ 2 条基线**、纵向重叠 ≥ 50%、
  跨缝的 run 必须全在带外（上/下）。
  「≥2 条基线」这条是分水岭：表格的一行、目录的一行、`30 cm × 30 cm × 1 cm`
  这类行内宽空格都只有 1 条基线，不会被当成分栏。
- **横带**：整幅宽度上都没有 run 的横条，高度 ≥ 12 pt（正文行距空隙只有 2–4 pt）。
- 竖缝优先于横带，与 `detectColumns` 一致（否则左栏会被切成上下两半，阅读顺序变成
  「左上、右上、左下、右下」）。
- 扫描线用事件表（`+1/-1`）而不是「对每个中点遍历所有 run」：单页上千 run 时后者是
  O(n²)，409 页样书上会变成每页几十毫秒。

### 3.2 `PDFLineBuilder`：逐区域建行、逐区域并碎片

`buildLines` 先 `PDFRegionCutter.regions(runs)`，再对每个区域调 `makeLines`，
`mergeInlineFragments` 也在**区域内部**做——跨区域的合并正是「作者+标题」黏在一起的
直接原因（角标把缝挤到 12 pt，落在 `1.0 em` 的并合判据里）。
另加一道兜底：只有**碎片**（去空白后 ≤ 4 字）才允许并回本行，
两侧都是整句时一律不并。

### 3.3 排版侧：扩框不许越过右边的邻居

中文比英文长，窄块（通讯作者的电话/邮件行）会走「扩框向右」，而
`columnRightEdge` 只看「左边界相同的块」取最宽右边界——首页左栏分两截
（前部信息窄、正文宽），于是窄块按正文的栏宽去扩，直接压到右栏的「关键词」上，
「电子邮件」与「关键词」两个字叠成一团。

`blockLimits` 增加约束：右边界不得越过**同一纵向带里的右边邻居**（`other.box.x0 - 2`），
但也不缩到原框以内。

### 3.4 顺带修掉的两处

- **旋转小字**：期刊在插图右缘竖排印 6 pt 的 `Int. Microbiol.`（10 页里 2 条），
  以前被翻成「微生物学」并压在图上（自检 `text-over-figure=1`）。
  新增 `PDFTypesetEngine.isRotatedLabel`（角度非零 + ≤2 行 + ≤80 字）→ 保持原字节。
- **缺字上下标**：模型把水写成 `H₂O`，思源宋体没有 U+2082，这个字被丢掉，
  印出来是「H O」。新增 `PDFGlyphFallback`：字体确实画不出时把上下标数字换成 ASCII
  （`H₂O → H2O`）。装饰符号（`⇑`、`✓`）**不换**，缺字要如实报告。
- 顺带把「钉子块」的两份条件清单合成一份 `keepsOriginal`：以前排版循环和翻译阶段
  各抄一份，一旦不同步就会出现「排版时钉住、翻译时照翻」的裂口。

## 6. 边界（不粉饰）

- **栏距比字距还小**的极端版面（例如栏距 10 pt @ 12 pt 字 = 0.8 em）仍然切不开：
  那时「栏缝」和「宽词距」在几何上无法区分，只能靠阅读顺序推断，本轮没做。
- 作者名单现在是一整块，中文重排后 9 个名字连成一段（原来是一行一个）。
  没有额外的「作者列表」识别规则；如果要一行一个，需要在 P2 输出里加 `type: author`。
- 单行表格、目录点线、行内宽空格靠「≥2 条基线」排除，不做语义判断。
- 无线表（第 3 页 Table 1）仍然是「按列钉住、保持原文」，不是重建表格。
- 参考文献仍会被翻译（既有边界）。
- **重排页放不下时回落原文**：整页重排（reflow）里若某段连下限字号都放不下，
  以前是把溢出的行直接丢掉（静默删字），现在先用原文重排一遍——原文当初就在这个框里，
  一定放得下。代价是那一段留英文。本样本 10 页没有触发（回落 0 次），属于兜底路径。
- **R5 的基准改成「本次计划要排的文字」**：`H₂O` 被换成 `H2O` 后，
  若仍拿调用方给的原始译文比对，会把「换了写法」误报成「少画了字」。
  实测这一条把 3 个假阳性清零（`glyph-missing=3` → `codes=[]`）。
